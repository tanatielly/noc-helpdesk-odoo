Mapa Topológico de Rede
=======================

Visualização geográfica interativa dos equipamentos de rede no mapa do Brasil.

* Aba "Topologia" no formulário de ``network.equipment``
* Marcadores coloridos por status (ativo, manutenção, tickets abertos, inativo)
* Circuitos exibidos como linhas entre equipamentos
* Geocodificação automática do campo ``location`` via Nominatim (OpenStreetMap)
* Filtro por localização e VLAN
