Anotações Privadas
==================

Anotações e rascunhos privados por usuário.

* Cada usuário vê apenas suas próprias anotações (isolamento via ``ir.rule``)
* Suporte a dois estados: **Rascunho** e **Anotação**
* Editor de texto rico (HTML) para o conteúdo
* Visualização em kanban (com cores personalizáveis), lista e formulário
* Menu "Minhas Anotações" acessível a todos os usuários internos
